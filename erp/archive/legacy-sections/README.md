version of this site (Showcase, Teams, InAction, "Love Impacgo"). They were
no longer rendered anywhere and still linked into the removed CRM demo, so
they were moved out of `src/` on 2026-11-12. This folder is excluded from the
build, type check and lint (see `tsconfig.json` / `eslint.config.mjs`).
